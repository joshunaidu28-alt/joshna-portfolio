# M Joshna — AI Automation & Cybersecurity Portfolio

A responsive, animated static portfolio website built with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve the folder with a local development server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy

Upload the contents of this folder to GitHub Pages, Netlify, Vercel (static deployment), or your preferred web host. Keep the `assets` folder alongside `index.html` so the profile photo loads.

## Customize

- Edit content and project links in `index.html`.
- Change colors, layout, and responsive styling in `styles.css`.
- Change filtering, mobile navigation, and scroll reveal behavior in `script.js`.
- Replace `assets/joshna-profile.jpg` to use another portrait.

Project details are summarized from the supplied resume and project descriptions. Check each linked repository for the latest implementation details.
